# LevelOK

Discord-бот опыта и уровней для одного сервера. Написан на [discord.js v14](https://discord.js.org), карточка ранга рисуется через `@napi-rs/canvas`.

## Команды

| Команда | Кто может | Что делает |
| --- | --- | --- |
| `/rank [пользователь]` | все | Карточка ранга: место (топ-3 подсвечены), уровень, общий опыт, прогресс до следующего уровня, сколько осталось, сообщения. Большие числа сокращаются: `5.32K`, `1.24M` |
| `/leaderboard` | все | Таблица лидеров с переключением страниц (опыт сокращается так же: `5.32K`, `1.24M`) |
| `/settings` | право «Управлять сервером» | Панель настроек (Components V2): меню категорий («Опыт», «Роли награды», «Множители», «Повышение уровня»), у каждого пункта своя кнопка |
| `/xp add/remove/set` | право «Управлять сервером» | Добавить, убавить или установить опыт участника |
| `/level add/remove/set` | право «Управлять сервером» | Добавить, убавить или установить уровень участника |

Категория **Опыт** в `/settings`: у «Опыт за сообщение», «Интервал» и «Общий множитель» своя кнопка «Изменить»; переключатели **«Опыт в ветках»** и **«Опыт в форумах»** (посты форумов и медиаканалов) — там, где опыт выключен, сообщения не дают опыта и не учитываются в счётчике; плюс «Сбросить к умолчаниям».

Опыт начисляется за сообщения: случайно от `мин` до `макс`, умножается на общий множитель, не чаще одного раза за интервал. При повышении уровня бот поздравляет участника в том же канале.

### Изменение опыта и уровня

`/xp` и `/level` с подкомандами `add` / `remove` / `set` (в русском клиенте — «добавить» / «убавить» / «установить»), доступны с правом «Управлять сервером».

- `/xp` меняет общий опыт (не ниже 0).
- `/level add|remove` меняет уровень, сохраняя прогресс внутри уровня; `/level set` ставит участника в начало указанного уровня (0–1000).
- Роли-награды сразу синхронизируются: при повышении выдаются, при понижении роли за уровни выше нового снимаются. Сообщение о повышении при ручном изменении не отправляется.

### Сообщение о повышении уровня

`/settings` → **Повышение уровня**: включить/выключить сообщение, изменить текст (до 1000 символов), сбросить к стандартному. Под текстом — предпросмотр. Переменные:

| Переменная | Что подставляется |
| --- | --- |
| `{user}` | упоминание участника |
| `{name}` | имя участника на сервере |
| `{level}` | новый уровень |
| `{rewards}` | выданные роли-награды; если переменной нет в тексте, награда допишется отдельной строкой |

Сообщение пингует только самого участника — роли и `@everyone` из текста не упоминаются.

### Множители

`/settings` → категория **Множители**. Это дополнительные множители опыта, которые можно навесить на **канал, категорию или роль** и сделать **временными**:

- **Добавить множитель** — выберите канал/категорию или роль, затем в форме укажите значение (×0.1 – ×10) и срок.
- **Срок** — `1д`, `12ч`, `2д 6ч`, `30м`, `1 нед` (также `1d`, `12h`…) от 1 минуты до 365 дней. Поле пустое — множитель бессрочный. По истечении срока множитель отключается сам, а на экране видно обратный отсчёт.
- **Изменить** у правила — поменять значение и срок (форма заполнена текущими; новый срок отсчитывается от сохранения) или удалить его.
- Правило на **категорию** действует на все её каналы, правило на **канал** — на его ветки и посты форума. На одну цель — одно правило.

**Какой множитель применяется.** Множители не перемножаются и не складываются: для каждого сообщения берётся **наибольший** из подходящих — правила канала/категории, правила ролей автора и **общий множитель** из категории «Опыт». Например, при общем ×1, канале ×2 и роли ×3 участник с этой ролью в этом канале получит ×3. Правило, не превышающее общий множитель, не действует, и в списке это помечено.

### Роли награды

`/settings` → в меню категорий выберите **Роли награды**. Меню нужно только для выбора категории, а все действия — кнопки на самой странице:

- **Изменить** у награды — сменить роль (текущая уже выбрана) или удалить награду;
- **Добавить роль** — ввести уровень и выбрать роль;
- **Включить / Выключить** — суммирование ролей;
- ◀ ▶ — страницы по 5 наград.

Для каждого уровня (1–1000, до 20 наград) можно выбрать роль: бот выдаёт её, когда участник достигает уровня, и упоминает в поздравлении.

- **Суммирование включено** — участник хранит роли за все достигнутые уровни.
- **Суммирование выключено** — остаётся только роль за самый высокий достигнутый уровень, роли более низких наград снимаются.

Роли синхронизируются, когда участник получает опыт, поэтому награда, добавленная позже, достанется и тем, кто уже набрал нужный уровень. Награду нельзя привязать к `@everyone` и ролям интеграций. Уже выданные роли при удалении награды не снимаются.

Чтобы бот мог выдавать роли, ему нужно право **«Управление ролями»**, а его собственная роль должна стоять **выше** ролей-наград (Настройки сервера → Роли). Если это не так, в списке наград рядом с ролью появится ⚠️.

Кривая уровней: чтобы перейти с уровня `N` на `N+1`, нужно `5·N² + 50·N + 100` XP (100, 155, 220, 295, …).

## Запуск

### 1. Что нужно

- [Node.js](https://nodejs.org) **18.17 или новее** (рекомендуется 20 или 22 LTS).
- Бот в [Discord Developer Portal](https://discord.com/developers/applications).

### 2. Настройка бота в Developer Portal

1. **Bot → Reset Token** — скопируйте токен. Никому его не показывайте и не заливайте в git.
2. Privileged Gateway Intents включать **не нужно** — бот обходится без них.
3. **OAuth2 → URL Generator**: отметьте scopes `bot` и `applications.commands`, в Bot Permissions — `View Channels`, `Send Messages`, `Embed Links`, `Attach Files`, `Manage Roles`. Откройте полученную ссылку и добавьте бота на свой сервер.

   Или используйте готовую ссылку, подставив ID приложения (General Information → Application ID):

   ```
   https://discord.com/oauth2/authorize?client_id=ВАШ_APPLICATION_ID&scope=bot+applications.commands&permissions=268487680
   ```

### 3. Установка

```bash
git clone https://github.com/vladcuk/LevelOK.git
cd LevelOK
npm install
```

Скопируйте `.env.example` в `.env` (Windows: `copy .env.example .env`, Linux/macOS: `cp .env.example .env`) и заполните:

```env
DISCORD_TOKEN=ваш_токен
GUILD_ID=id_вашего_сервера
```

`GUILD_ID` — ПКМ по серверу → «Копировать ID сервера» (нужен включённый «Режим разработчика» в настройках Discord → Расширенные). Если оставить пустым, бот зарегистрирует команды на всех серверах, где он состоит.

### 4. Старт

```bash
npm start
```

В консоли появится `Вошёл как ...` и `Зарегистрированы на сервере ...` — команды сразу доступны на сервере.

### Работа 24/7

Бот работает, пока запущен процесс. Чтобы он был онлайн постоянно, запустите его на VPS/хостинге, например через [pm2](https://pm2.keymetrics.io):

```bash
npm install -g pm2
pm2 start src/index.js --name levelok
pm2 save
pm2 startup   # автозапуск после перезагрузки сервера
```

## Данные

Опыт и настройки хранятся в `data/db.json` (создаётся автоматически, в git не попадает). Для переноса бота на другую машину просто скопируйте эту папку. Делайте её резервные копии.

## Структура

```
src/
  index.js              запуск, начисление опыта, обработка взаимодействий

  levels.js             формула уровней и расчёт опыта

  rewards.js            выдача и снятие ролей-наград
  adjust.js             логика /xp и /level
  levelup.js            текст о повышении уровня, опыт в ветках/форумах
  multipliers.js        выбор наибольшего множителя (канал/категория/роли)
  duration.js           разбор срока («1д 12ч»)
  card.js               отрисовка карточки ранга
  commands/
    rank.js
    leaderboard.js
    settings.js
    xp.js
    level.js
scripts/preview-card.js   npm run preview → preview.png (пример карточки без запуска бота)
```
